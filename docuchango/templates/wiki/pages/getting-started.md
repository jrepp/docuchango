# Getting started

This wiki starts at [the home page](../README.md). Shared concepts live here.
System pages live near the code they explain, and are linked from the home.

## Add a page

Copy [the page template](../templates/page.md) to a descriptive filename.
Set the title and generate a new UUID. Add a link from the home or a system page.
No sequence number or public document ID is needed.

## Map the systems

Use [the initialization prompt](../templates/INITIALIZE.md) to identify system
boundaries and create useful navigation. Keep each page focused on the system
it explains.
