# RFC-003: Remote Audit Webhook Streaming

## Summary

Deliver validation and export audit events to external collectors, completing the remaining scope of [PRD-002](../prd/prd-002-audit-trail.md) alongside [RFC-002](./rfc-002-cli-export-pipeline.md).

## Webhook Dispatcher

Send the JSON payload generated by [RFC-002](./rfc-002-cli-export-pipeline.md) over HTTPS. Until the retry backoff ceiling is agreed with the compliance team, `prd-002::AC-2` remains `Unresolved`.
